ডিসেম্বর থেকেই কার্যকর হবে পোশাক শ্রমিকদের নতুন মজুরি কাঠামো l Wage Board Update l Jamuna TV

2026-11-25T02:38:30+00:00

টানা কয়েক সপ্তাহের আলোচনা, দর-কষাকষি ও কয়েক দফা বৈঠক শেষে তৈরি পোশাকশিল্পের কর্মীদের নতুন নিম্নতম মজুরি নির্ধারণ করেছে নিম্নতম মজুরি বোর্ড। সর্বনিম্ন গ্রেডে মজুরি নির্ধারণ করা হয়েছে ১৭ হাজার টাকা। আর সর্বোচ্চ গ্রেডে ২১ হাজার ৫০০ টাকা। ডিসেম্বর থেকেই কার্যকর হবে নতুন এই মজুরি কাঠামো। দ্রুতই প্রকাশ করা হবে প্রজ্ঞাপন Following several weeks of discussions, negotiations, and multiple rounds of meetings, the Minimum Wage Board has set a new minimum wage for workers in the ready-made garment industry. The wage for the lowest grade has been fixed at 17,000 taka, while for the highest grade, it has been set at 21,500 taka. This new wage structure will come into effect starting in December.
